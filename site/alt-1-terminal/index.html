mliprun
Runs Install GitHub

Run machine-learning potentials with one command.

mliprun is a CLI and a small web app for machine-learning interatomic potentials (UMA, MACE, SevenNet, CHGNet): relaxations, committees, NEB with transition-state checks, MD, and remote runs on GPU machines you add yourself. This page replays real runs of O on Pt(111): the commands as typed, the output as logged.

Each use case as the command that ran and what it returned. Numbers are read at load time from the run data, with units and convergence status. All runs ran on cos-cluster; paths in the commands are where these runs happened (elided, full form one click away), not paths to use.

mlip optimize run

Relax one adsorbate: O placed at the fcc hollow of a 3×3 Pt(111) slab.


        
      

      

      

    

  


  

    

      
mlip optimize run --committee

      
The same relaxation driven by the mean force of three models, each in its own
        environment. Their disagreement is the error bar.

      

    

    

      

      

      

      

      

    

  


  

    

      
mlip neb run --verify-ts both

      
Climbing-image NEB between the two hollows, then a check of the top image: one
        imaginary mode, along the path, and relaxing down to both ends.
        Replayed at the top of the page.

Finite-temperature MD of a water bilayer on Pt(111).

Install

    
One MLIP per environment. The full recipe, the asetools warning and the gated UMA
      steps are in the README
      and AGENTS.md.

    
git clone https://github.com/manuelarcer/mliprun.git && cd mliprun
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[neb]"
pip install mace-torch        # or fairchem-core (UMA, gated), sevenn, chgnet
mlip doctor
