mlip webapp

      
The same relaxation, sent from the browser to a remote GPU machine.

      
No machines are preconfigured; you add your own.

      
Add your machine
      
    
        
  1. Run mlip webapp on your laptop.
    2. 
        
  2. Machines → Add machine: Name, Host <your ssh alias> (an alias from ~/.ssh/config), Default remote location <your remote folder>. Press Add machine.
    3. 
        
  3. On the saved machine: Add environment, Python path <your uma env>/bin/python, and a name.
    4. 
        
  4. Test connection on the saved machine, then submit a job to it.
    5.

Install

    
One MLIP per environment. Full recipe: INSTALL, AGENTS.md.

    
git clone https://github.com/manuelarcer/mliprun.git && cd mliprun
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[neb]"
pip install mace-torch        # or fairchem-core (UMA, gated), sevenn, chgnet
mlip doctor
