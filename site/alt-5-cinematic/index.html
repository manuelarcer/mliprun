Run it on your own GPU machine from the web app

No preconfigured machines: add your own in the web app.

How to add a machine
  1. Machines, Add machine: Name, Host (<your ssh alias> from ~/.ssh/config), Default remote location (<your remote folder>).
  2. On the saved machine: Add environment, Python path <your uma env>/bin/python.
  3. Test connection, then submit.

Install

One MLIP per environment.

git clone https://github.com/manuelarcer/mliprun.git
cd mliprun
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[neb,webapp]"
pip install mace-torch   # or fairchem-core (UMA, gated), sevenn, chgnet
mlip doctor

Full installation instructions (docs/INSTALL.md)

Also in mliprun

  • freq run vibrational frequencies, imaginary-mode count and zero-point energy
  • autoneb run NEB with dynamic image insertion
  • benchmark compare models on one set of structures
  • singlepoint run energy, forces and stress without relaxing
  • UMA, MACE, SevenNet and CHGNet, each in its own environment
  • mlip doctor checks that an environment can run its model
