Which machine, which environment, which command. No preconfigured machines: you add your own. Every result below is a real run.

Code that ran: mliprun commit …. Model for single-model runs: uma-s-1p2 with the oc20 head. The showcase runs ran on cos-cluster (one GPU card).

Five results at a glance

Setup

Once per machine; the recipes assume it.

Which machine

Your laptop, or a remote GPU machine you add yourself.

What a remote machine needs
Login
Password-free SSH: an SSH key, or a ControlMaster connection you opened.
System
Linux with /bin/sh; nvidia-smi optional (GPU table).
Python
An environment with mliprun installed.
Shared GPUs
No scheduler? Check the GPU table and use one free card.
# on your GPU machine: which cards are busy?
nvidia-smi
export CUDA_VISIBLE_DEVICES=<free card>

Which environment

One MLIP per Python environment, with mliprun installed in each.

git clone https://github.com/manuelarcer/mliprun.git
cd mliprun
python3 -m venv <your uma env>     # a folder you choose
source <your uma env>/bin/activate
pip install -e .
pip install fairchem-core      # UMA; one MLIP package in this env only
Why, and install pitfalls

mace-torch, fairchem-core, sevenn and chgnet pin conflicting torch and e3nn versions; two in one environment can break one silently. UMA weights are gated on Hugging Face: each person requests access once and logs in with a token (UMA guide). MACE needs no access request. Never pip install asetools: the PyPI package of that name is unrelated. Use pip install -e ".[neb]". Per-MLIP recipes: docs/install.

Check the environment

After every install: versions, installed MLIPs, CUDA; non-zero exit if no MLIP.

source <your uma env>/bin/activate
mlip doctor

Always name model and head: --mlip uma-s-1p2 --uma-task oc20.

Add your machine in the web app

Runs on your laptop; sends jobs over SSH to the machine you add.

pip install -e ".[webapp]"     # on the laptop only
mlip webapp                    # opens http://127.0.0.1:8765/
  1. Machines → Add machine. Name: any. Host: <your ssh alias> (from ~/.ssh/config). Default remote location: <your remote folder>. Press Add machine.
  2. Add environment, on the saved machine's card. Python path: <your uma env>/bin/python, plus a Name.
  3. Test connection, on the saved machine. Shows the host and the GPU table; it does not check the load.
  4. Run on. In the job form, choose your environment; submit.
