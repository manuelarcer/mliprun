# Front-page showcase runs

This folder holds the real mliprun calculations behind the project README and landing-site animations: an O/Pt(111) relaxation, a committee relaxation, an O fcc→hcp NEB with transition-state verification, and an H2O-bilayer MD run, all on the cos-cluster GPU node. They demonstrate the tool and are not publication results. The calculation settings are binding and live in [CANON.md](CANON.md). The design is in [the spec](../superpowers/specs/2026-11-17-front-page-showcase-design.md), and the cluster paths are in `cluster.env` and `committee.yaml`.
